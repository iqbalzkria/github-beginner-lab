Makmal GitHub Pertama Saya

Laman latihan ringkas untuk faham bagaimana GitHub menyimpan fail projek, merekod perubahan dan membantu orang bekerjasama.

Projek pertama kau

Bayangkan GitHub sebagai rumah projek yang ada buku sejarah.

Fail projek disimpan dalam repository. Setiap commit merekod perubahan. Branch beri ruang selamat untuk mencuba. Pull request pula membolehkan perubahan disemak sebelum digabungkan ke versi utama.

Gambaran besar
Rancang → Bina → Semak

GitHub bukan sekadar tempat simpan coding. Ia juga membantu kita mengurus kerja sesebuah projek.

Checklist latihan GitHub

Tandakan setiap langkah selepas kau berjaya buat di GitHub.

0 daripada 7 selesai

Enam istilah GitHub yang penting

Repository

Folder projek

Tempat menyimpan fail berkaitan projek serta sejarah perubahannya.

Commit

Snapshot yang disimpan

Rekod perubahan yang disimpan bersama mesej ringkas.

Branch

Ruang kerja berasingan

Tempat mencuba atau membina perubahan tanpa mengganggu versi utama.

Pull request

Cadangan perubahan

Tempat membincangkan dan menyemak perubahan sebelum merge.

Issue

Tugasan atau masalah

Untuk merekod bug, idea, soalan atau penambahbaikan.

GitHub Pages

Terbitkan website

Servis untuk menerbitkan laman web statik daripada repository.

Aliran kerja biasa di GitHub

Issue→Branch→Edit fail→Commit→Pull request→Semak→Merge
