# Makmal GitHub Pertama Saya

Projek website kecil untuk belajar fungsi utama GitHub secara praktikal.

## Apa yang ada dalam projek ini?

- `index.html` — laman web latihan yang mengandungi checklist, kamus istilah GitHub dan gambar rajah aliran kerja.
- `README.md` — penerangan projek dan arahan latihan.

## Cuba di komputer sendiri

1. Muat turun ZIP projek dan extract/unzip.
2. Buka folder `github-beginner-lab`.
3. Klik dua kali fail `index.html` untuk buka website dalam browser.

Tak perlu install software atau internet untuk melihat preview laman ini.

## Terbitkan melalui GitHub Pages

1. Cipta repository bernama `github-starter-lab` di GitHub.
2. Untuk latihan ini, pilih **Public** supaya boleh diterbitkan menggunakan GitHub Free.
3. Upload fail `index.html` dan `README.md` ke branch `main`.
4. Buka **Settings → Pages**.
5. Di bahagian **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/(root)`, kemudian klik **Save**.
7. Tunggu proses deployment selesai. GitHub akan memaparkan alamat website di bahagian Pages.

Website yang diterbitkan adalah public. Jangan letakkan maklumat sulit dalam projek latihan ini.

## Misi latihan: buat perubahan pertama

1. Buka tab **Issues** dalam repository dan cipta issue bertajuk `Tambah ucapan alu-aluan Bahasa Melayu`.
2. Pada pemilih branch, cipta branch bernama `feature/malay-welcome` daripada `main`.
3. Buka fail `index.html` dalam branch tersebut dan tukar tajuk utama daripada `Makmal GitHub Pertama Saya` kepada `Selamat Datang ke GitHub!`.
4. Commit perubahan dengan mesej `Tambah tajuk alu-aluan Bahasa Melayu`.
5. Buka pull request daripada `feature/malay-welcome` ke `main`.
6. Semak tab **Files changed**. Kalau perubahan betul, klik **Merge pull request**.
7. Kembali ke branch `main`. Perubahan tajuk kini menjadi sebahagian daripada versi utama. GitHub Pages akan menerbitkan kemas kini selepas deployment selesai.

## Maksud istilah utama

| Istilah GitHub | Maksud mudah |
|---|---|
| Repository | Rumah untuk fail dan sejarah projek |
| Commit | Snapshot perubahan yang disimpan |
| Branch | Ruang kerja berasingan untuk membina perubahan |
| Issue | Tugasan, idea, soalan atau masalah untuk dijejak |
| Pull request | Cadangan untuk semak dan gabungkan perubahan |
| Merge | Gabungkan perubahan ke branch lain |
| GitHub Pages | Terbitkan website statik daripada repository |
## Nota Latihan Revert

## Nota keselamatan penting

Jangan upload maklumat pelanggan sebenar, kata laluan, API key, access token atau dokumen sulit syarikat ke repository public. Gunakan contoh rekaan sahaja.

Nota: checklist dalam website menyimpan progress dalam browser/peranti yang digunakan. Ia bukan pangkalan data bersama dan tidak menghantar data checklist kepada GitHub.
